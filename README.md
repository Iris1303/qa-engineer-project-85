# Тестирование в продакшене

**CodeBattle**

*Codebattle* — игра, в которой два программиста одновременно выполняют одну задачу на разных языках программирования. Кто выполнил быстрее, тот побеждает.

Вся тестовая документация находится в этом репозитории в виде .yml файлов:

- `requirements.yml` – Описание функциональных, нефункциональных и неявных требований проекта

- `test-cases.yml` – Подробные тест-кейсы для проведения тестирования

- `testing-report.yml` – Результат прохождения тест-кейсов с отметкой об их успешности или провальности

- `issues.yml` – Ссылка на открытые баги с подробным описанием дефектов и шагов по их воспроизведению

- `reopened_issues.yml` – Отчет о проведенном регрессионном тестировании по закрытым баг-репортам проекта
